## Lo que suelo resolver

- **Del relevamiento a producción:** entender cómo trabaja el negocio, diseñar el sistema, ponerlo en
  marcha y darle soporte.
- **Lógica de negocio segura en la base de datos:** funciones transaccionales, seguridad por filas
  (RLS) y operaciones idempotentes que no se duplican aunque se corte la señal.
- **Apps que funcionan sin conexión** y se sincronizan solas al volver la señal.
- **Documentos comerciales** (facturas, notas, recibos) en PDF e imagen, listos para WhatsApp.
- **Interfaces simples** para usuarios sin experiencia técnica, con validaciones claras.
